# Routes

This app is a **TanStack Router SPA** (Vite, client-only) — not TanStack Start. There is no
server entry, no `createServerFn`, and no SSR. The upstream Lovable frontend
(`jackye426/data-verse-render`) *is* TanStack Start; don't copy its server-side patterns here.

Routing is file-based: every `.tsx` file in this directory defines a route. Do **not** create
`src/pages/`, `src/routes/_app/index.tsx`, or `app/layout.tsx` — those are Next.js / Remix
conventions. The only root layout is `src/routes/__root.tsx`.

## Conventions

| File | URL |
| --- | --- |
| `index.tsx` | `/` |
| `about.tsx` | `/about` |
| `users/index.tsx` | `/users` |
| `users/$id.tsx` | `/users/:id` (dynamic — bare `$`, no curly braces) |
| `posts/{-$category}.tsx` | `/posts/:category?` (optional segment) |
| `files/$.tsx` | `/files/*` (splat — read via `_splat` param, never `*`) |
| `_layout.tsx` | layout route (renders children via `<Outlet />`) |
| `__root.tsx` | app shell — wraps every page; preserve `<Outlet />` and `<HeadContent />` |

`routeTree.gen.ts` is auto-generated by the router Vite plugin. Don't edit it by hand.

Per-route `head: () => ({ meta })` is rendered by `<HeadContent />` in `__root.tsx`; removing it
silently disables every route's title and OG tags.
